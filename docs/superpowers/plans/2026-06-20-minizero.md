# minizero / code lab (Plan 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or executing-plans. Steps use checkbox (`- [ ]`) tracking. Execution-lean: per-task DoD + test targets, not full transcribed code (the spec holds the design; the inline executor writes the code under TDD).

**Goal:** A pure-NumPy imperfect-information algorithm lab + an AlphaEvolve-style auto-loop + the shippable R-NaD neural challenger.

**Architecture:** `minizero/` holds runnable, self-verifying algorithms (CFR on Kuhn, tabular R-NaD on Leduc, ISMCTS on the real cg sim). The net trains on GPU (torch) and ships as a NumPy forward pass (`agent_net.py`). `tools/evolve.py` automates the keep/revert loop. All challengers face the existing `eval.py` Wilson-LB gate.

**Tech Stack:** Python 3.11 + NumPy (lab); torch (training, dev/GPU only); the `cg` SDK + Docker (cg env); `pytest`.

## Global Constraints
- Shipped agent stays offline/stdlib — NO LLM, NO torch at inference. `minizero/` and `colab/` never ship.
- Each algorithm is self-verifying: CFR/R-NaD must drive **exploitability → ~0** on their toy game (the correctness oracle). That assertion IS the test.
- Single-process default; parallelism opt-in via `n_workers`.
- A challenger replaces the champion only via the existing `eval.py` gate (mirror Wilson-LB ≥ 0.48 AND Dragapult ≥ baseline).
- Steps 1–4 need NO GPU/Docker-GPU; step 3 (cg) needs Docker; steps 5–6 need Docker/GPU (colab-mcp runner — restart Claude Code to load its tools first).

---

### Task 1 — CFR on Kuhn poker  [no infra]
**Files:** `minizero/cfr/kuhn.py`, `minizero/cfr/cfr.py`, `minizero/cfr/exploit.py`, `minizero/cfr/run.py`, `minizero/cfr/test_cfr.py`, `minizero/README.md`
- `kuhn.py`: Kuhn poker game tree (3 cards, info sets keyed by card+history).
- `cfr.py`: vanilla CFR + regret matching; accumulate the **average** strategy (the thing that converges — see wiki/10).
- `exploit.py`: best-response value → exploitability.
- **DoD / test:** after N iterations, exploitability < 1e-2 and the learned strategy matches Kuhn's known Nash family (player-1 bet-prob α∈[0,1/3], etc.). Test asserts exploitability decreases and converges. `run.py` prints the exploitability curve.

### Task 2 — MCCFR external sampling  [no infra, small]
**Files:** `minizero/cfr/mccfr.py` (+ test)
- External-sampling MCCFR reusing `kuhn.py`/`exploit.py`.
- **DoD / test:** converges to the same Nash (exploitability < 2e-2) in fewer full-tree touches. Optional `n_workers` (multiprocessing) merging regret deltas. `ponytail:` if Task 1 is enough teaching value, this is a documented stretch — keep minimal.

### Task 3 — ISMCTS on the real cg sim  [needs Docker]
**Files:** `minizero/cg/cg_env.py`, `minizero/cg/ismcts.py`, `minizero/cg/run.py`
- `cg_env.py`: thin wrapper over `sdk/cg` `search_begin/step/end` + `_determinize` (lift from `autoresearch/agent_search.py`).
- `ismcts.py`: PUCT info-set MCTS, re-determinize per simulation; optional root parallelization.
- **DoD / test (in Docker):** returns a legal action index for sampled real cg Observations across N states, never raises.

### Task 4 — tabular R-NaD on Leduc  [no infra] — the net's correctness oracle
**Files:** `minizero/rnad/leduc.py`, `minizero/rnad/rnad_tabular.py`, `minizero/rnad/test_rnad.py`
- `leduc.py`: Leduc poker env. `rnad_tabular.py`: R-NaD update (regularize toward a reference policy, iterate; see wiki/12) in pure NumPy.
- **DoD / test:** exploitability on Leduc decreases and converges below a small ε — proves the R-NaD update before any GPU spend.

### Task 5 — `tools/evolve.py` (AlphaEvolve auto-loop)  [needs Docker]
**Files:** `tools/evolve.py` (+ dry-run test)
- Propose mutation to `agent_lucario.py` → score via `eval.py` against the gate → auto-keep on PROMOTE → append to `experiments.md`. Parallel candidate eval. No runtime LLM in the agent.
- **DoD / test:** dry-run produces a candidate, scores it, logs it, and does NOT mutate the champion when the candidate loses.

### Task 6 — neural R-NaD + shippable net  [needs GPU via colab-mcp]
**Files:** `minizero/rnad/net.py` (torch), `minizero/rnad/train.py`, `minizero/rnad/export.py`, `agent_net.py`, runner driver
- Reuse the Task-4 R-NaD update with a torch net on the cg env; `export.py`: torch → `weights.npz`; `agent_net.py`: NumPy forward pass, mask illegal actions, pick (same `agent(obs_dict)->list[int]` contract).
- **DoD / test:** round-trip — torch forward and NumPy forward agree within tolerance (guarantees `agent_net.py` matches the trained net); `agent_net.py` smoke returns a legal action and never raises. Then train on GPU and submit to the `eval.py` gate.
